# Our Memory Box

เว็บเซอร์ไพรส์วันเกิดแบบ static 3D โทนชมพู — React, TypeScript, Vite, Three.js, React Three Fiber, Drei, GSAP และ Motion

## เปิดโปรเจกต์

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง รหัสตัวอย่างคือ `180926`

```sh
npm run build
npm run preview
```

ไฟล์พร้อมสำหรับ static hosting อยู่ใน `dist/` รองรับการวางใน subdirectory ผ่าน Vite base แบบ relative ไม่มี backend

## ใส่เรื่องราวของเรา

แก้ `src/content.ts` สำหรับชื่อเล่น รหัส คำใบ้ จดหมาย ข้อความจบ และคำบรรยายรูป

1. ใส่รูป 5–8 รูปใน `public/assets/personal/` (สร้างโฟลเดอร์นี้ก่อน)
2. เปลี่ยน `memories[].image` เป็น `asset('personal/01.webp')` และปรับ `title`, `date`, `caption`, `alt` ให้ตรงกับภาพ
3. ตั้ง `sample: false` เพื่อลบป้ายภาพตัวอย่าง ใช้ภาพจัตุรัสหรือใกล้เคียงจัตุรัสเพื่อให้ครอปสวย ภาพจะถูก crop แบบ cover ในกรอบ
4. ใส่ `birthday.mp4` แล้วตั้ง `video: asset('personal/birthday.mp4')` แนะนำ MP4 H.264/AAC, 720p–1080p, ไม่เกินประมาณ 30 MB และ 30–60 วินาที
5. ใส่ภาพปกวิดีโอที่ `videoPoster` ได้ ถ้ายังไม่มีวิดีโอเว็บจะมีการ์ดรอวิดีโอและปุ่มอ่านข้อความสุดท้าย

ไฟล์ส่วนตัวถูก ignore จาก Git แต่จะถูกคัดลอกไปใน build ดังนั้นเพิ่มไฟล์ก่อน build จริง อย่าลืมตรวจเนื้อหาตัวอย่างทั้งหมดก่อนส่งให้แฟน

## เรื่องราวทั้ง 6 ฉาก

รหัส → เปิดกล่อง 3D → จดหมาย → รูปไหลทีละใบ → ผนังรวมความทรงจำ → วิดีโอและข้อความสุดท้าย

เพลงเริ่มหลังแตะปุ่มเปิดเพลงเท่านั้น มีปุ่มปิดเพลงตลอดเรื่อง เพลงหยุดระหว่างวิดีโอและเมื่อซ่อนแท็บ ภาพไม่เลื่อนเองจนกดชมต่อเนื่อง มีปุ่มหยุด/ก่อนหน้า/ถัดไป รองรับ reduced motion และการใช้งานคีย์บอร์ด หาก WebGL ใช้ไม่ได้ยังอ่านและไปต่อครบทุกฉากได้

## โมเดลและเสียง

อ่าน `docs/ASSET-CREDITS.md` ก่อนเผยแพร่ โดยเฉพาะเครดิต CC BY 3.0 ของกล่องและข้อกำหนดการแจกไฟล์เสียง Mixkit

ไฟล์เสียงที่ดาวน์โหลดไว้ใช้ในการ build เว็บนี้ได้ แต่ไม่ถูก commit เพื่อหลีกเลี่ยงการแจกเป็น asset pack หากย้ายเครื่องต้องนำไฟล์เสียงไปด้วยตามลิงก์ในเอกสารเครดิต

PIN ในเว็บ static เป็นส่วนหนึ่งของเซอร์ไพรส์ ทุกไฟล์ที่นำขึ้น hosting สามารถเข้าถึงได้ ไม่ใช่ระบบป้องกันข้อมูลส่วนตัวจริง

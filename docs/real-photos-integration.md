## การแสดงผล

- การ์ด 3D มีช่องภาพ 1.27 × 1.693 หน่วย ใกล้เคียงภาพจริง 1108 × 1477 และพิมพ์วันที่ที่ขอบล่าง
- ใช้ตำแหน่งคงที่แบบไม่สมมาตร 9 จุด แยกแนวตั้งและแนวนอน ระยะลึกและมุมเอียงแตกต่างกัน เลือกดูรูปใดก่อนก็ได้
- แยกจิ๊กซอจาก `memories[0]` เป็น `content.puzzle` ครอปด้วย CSS เฉพาะเกมโดยโฟกัสด้านล่างและซูม 1.28 เท่า หลังต่อครบแสดงภาพต้นฉบับแนวตั้ง ไม่ใส่วันที่ที่ไม่ทราบ
- โหลดภาพการ์ดผ่าน Suspense เฉพาะช่องภาพ เพื่อไม่ให้การโหลดรูปพักทั้งฉาก และโหลดภาพจิ๊กซอระหว่างเปิดจดหมาย
- จำนวนวัตถุที่เผยและรวมหัวใจยังคำนวณจากรายการภาพ: 9 รูป + 3 กิจกรรม + 3 ข้อความตกแต่ง + 5 หัวใจ = 20 วัตถุ

## จุดแตะถูกบังโดยไกด์

การตรวจพบว่าตอน `.guide-obscured` ซ่อนไกด์และกำหนด `pointer-events:none` ที่ปุ่ม Canvas ของ React Three Fiber ตั้ง `pointer-events:auto` ที่ wrapper ของตัวเอง ทำให้ส่วนที่มองไม่เห็นยังขวางการแตะรูป

ทดลองเปลี่ยนเฉพาะ pointer-events ของ wrapper แล้วจุดเดิมแตะผ่านถึง Canvas หลักได้ และเมื่อย้อนกลับก็ถูกบังอีกครั้ง หลักฐานอยู่ใน `real-photos-pointer-proof.json` แก้ที่ Canvas ของไกด์ด้วย `style={{ pointerEvents:'none' }}` ปุ่มไกด์ยังรับคลิกได้เมื่อแสดงตามปกติ

## การตรวจสอบ

- `npm run build`: ผ่าน TypeScript และ production build
- `real-photos-qa.json`: 16 รายการ ตรวจ viewport 834×1194, 1194×834, 1440×900 และ 768×1024; แตะโมเดลภาพจริงทั้ง 9 ใบ; เล่นจิ๊กซอด้วยการสลับจนจบ; ตรวจภาพทั้ง 9 หายครบหลังรวมเข้าหัวใจ
- ก่อนและหลังเปลี่ยนจาก revealing เป็น exploring ตำแหน่ง root ของภาพทั้ง 9 ใบตรงกัน ไม่สร้างการ์ดชุดใหม่
- ตรวจภาพหน้าจอจริงสำหรับจักรวาล รูปเต็ม และจิ๊กซอทั้งสองแนว
- `real-photos-production-qa.json`: 15 รายการบน Vite preview; รูปทั้ง 10 ไฟล์ตอบ HTTP 200 และเป็น JPEG; ปุ่มอ่านคำแนะนำของไกด์ยังกดได้; การ์ดคำสัญญาและวิดีโอทำงาน; จิ๊กซอซูม 1.28 และเผยภาพเต็มทันทีในโหมดลดการเคลื่อนไหว; หน้าจอ 390×844 เปิดรูปเต็มได้และไม่มี horizontal overflow
- การตรวจ viewport ใช้ Chromium/SwiftShader ไม่ใช่ผลทดสอบบนอุปกรณ์ iPad จริง

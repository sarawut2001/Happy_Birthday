# สคริปต์วิดีโอ 30–60 วินาที

“สุขสันต์วันเกิดนะ [ชื่อเล่น]

เป็นไงบ้าง ชอบของขวัญปีนี้ไหม เรานั่งทำไปก็คิดถึงเรื่องของเราไป ยิ้มอยู่คนเดียวเลย

ขอบคุณที่อยู่ด้วยกันนะ โดยเฉพาะ [ใส่เรื่องจริงสั้น ๆ หนึ่งเรื่องที่อยากขอบคุณ เช่น วันที่เขาอยู่เป็นเพื่อนตอนเหนื่อย]

ปีนี้ขอให้เธอมีความสุขกับสิ่งที่ทำ ได้ลองอะไรที่อยากลอง แล้วก็ใจดีกับตัวเองเยอะ ๆ นะ วันไหนเหนื่อยก็มาหาเราได้เสมอ

อยากอยู่ฉลองวันเกิดกับเธอแบบนี้ไปอีกหลาย ๆ ปีเลย รักเธอนะ”

พูดตามภาษาที่ใช้กันจริง เปลี่ยนคำว่าเรา/เธอได้ ไม่ต้องอ่านให้เป๊ะ มองกล้องแล้วนึกว่ากำลังคุยกับแฟน อัดในที่เงียบ หันหน้าเข้าหาแสงหน้าต่าง เว้นตอนต้นและท้าย 1–2 วินาที
